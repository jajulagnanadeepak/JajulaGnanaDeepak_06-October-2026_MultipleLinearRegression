# 📊 Multiple Linear Regression — Advertising Dataset

## 📌 Project Overview

This project uses **Multiple Linear Regression** to understand how different advertising channels influence product sales and to predict future sales based on planned advertising budgets.

## 🎯 Business Scenario

A consumer goods company promotes its product through three advertising channels:

- 📺 Television (TV)
- 📻 Radio
- 📰 Newspaper

The objective is to understand how these channels influence **Sales** and predict sales for a given advertising budget.

---

## 📂 Dataset

**Dataset:** `advertising.csv`

| Property | Details |
|---|---|
| Rows | 200 |
| Columns | 4 |
| Features | TV, Radio, Newspaper |
| Target | Sales |
| Missing Values | 0 |
